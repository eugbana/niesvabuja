🧪 Manual Testing Instructions

Chrome DevTools Testing:

  1. Open Chrome DevTools (F12)
  2. Go to Application tab
  3. Check Service Workers section
  4. Check Manifest section
  5. Use Lighthouse tab to run PWA audit

Installation Testing:

  1. Look for install prompt in address bar
  2. Try installing the app
  3. Test app shortcuts (if supported)
  4. Test standalone mode

Offline Testing:

  1. Go to DevTools → Network tab
  2. Check "Offline" checkbox
  3. Navigate to different pages
  4. Test form submissions

🔍 Lighthouse PWA Audit

Run a Lighthouse audit to get a comprehensive PWA score:

Expected PWA Criteria:

  • ✅ Registers a service worker
  • ✅ Responds with a 200 when offline
  • ✅ Contains a web app manifest
  • ✅ Manifest has a maskable icon
  • ✅ Has a themed address bar
  • ✅ Content is sized correctly for the viewport
  • ✅ Displays images with appropriate aspect ratio
